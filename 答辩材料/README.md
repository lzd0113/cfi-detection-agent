# 答辩材料

| 文件 | 说明 | 大小 |
|------|------|------|
| CFI_Agent_presentation.pptx | 答辩 PPT | 0.1 MB |

| cfi_detection_report.xlsx | 检测结果 Excel 报告（4 Sheet） | 0.4 MB |

| detection_demo.mp4 | 检测过程演示视频 | 14 MB |

## 使用说明

1. 下载整个仓库或 答辩材料/ 文件夹
2. 将所有文件放在同一个文件夹中
3. 如果文件无法打开（Windows 安全限制）：右键文件 → 属性 → 勾选「解除锁定」→ 确定
4. PPT 中的超链接如无法打开，请用 Alt+Tab 手动切换到对应文件
